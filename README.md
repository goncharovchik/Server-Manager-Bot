# VDS Manager Bot

Telegram-бот на базе Node.js (Telegraf) для администрирования и мониторинга VDS сервера.

Приложение запускается непосредственно на сервере или в Docker-контейнере и выполняет системные команды через `child_process`. Подключение по SSH не требуется.

---

## Функциональные возможности

| Модуль | Описание | Команды |
|---|---|---|
| **Мониторинг** | Нагрузка CPU, использование RAM, дисков, сетевая статистика, uptime | `/status`, `/cpu`, `/ram`, `/disk`, `/network`, `/uptime` |
| **Сервисы** | Управление systemd-сервисами (список, запуск, остановка, перезапуск, статус) | `/services`, `/service_start`, `/service_stop`, `/service_restart`, `/service_status` |
| **Docker** | Управление контейнерами (список, запуск, остановка, перезапуск, логи) | `/containers`, `/container_start`, `/container_stop`, `/container_restart`, `/container_logs` |
| **Файлы** | Просмотр директорий, чтение файлов, выгрузка и загрузка файлов через Telegram | `/ls`, `/cat`, `/download`, `/upload` (reply с документом) |
| **Пользователи** | Просмотр учетных записей системы, создание и удаление пользователей | `/users`, `/useradd`, `/userdel` |
| **Firewall** | Просмотр статуса и правил UFW, управление портами | `/fw_status`, `/fw_rules`, `/fw_allow`, `/fw_deny` |
| **Shell** | Выполнение произвольных команд командной строки с таймаутом | `/shell <command>` |
| **Пакеты** | Обновление списков пакетов APT, обновление установленных пакетов, инсталляция | `/apt_update`, `/apt_upgrade`, `/apt_install` |
| **Резервное копирование** | Создание tar.gz архивов, листинг, восстановление и скачивание бэкапов | `/backup_create`, `/backup_list`, `/backup_restore`, `/backup_download` |
| **Журналирование** | Просмотр логов сервисов (journalctl), системных логов (syslog, auth.log) | `/logs`, `/syslog`, `/authlog` |

## Архитектура и безопасность

1. **Разграничение доступа (Whitelist):** обработка команд выполняется исключительно для учетных записей Telegram, указанных в `ADMIN_IDS`. Неавторизованные запросы отклоняются и фиксируются в журнале.
2. **Ограничение частоты запросов (Rate Limiting):** защита от перегрузки (по умолчанию не более 30 команд в минуту на пользователя).
3. **Журналирование (Winston):** сквозное логирование всех вызовов с ежедневной ротацией файлов.
4. **Фильтрация конфиденциальных данных:** автоматическая маскировка паролей, токенов и API-ключей в журналах логов (`***`).

## Требования и развертывание

### Требования
* Node.js 18+ (при локальном запуске)
* Docker и Docker Compose (при контейнеризации)

---

### Вариант 1. Развертывание в Docker Compose

Бот автоматически определяет запуск внутри контейнера и выполняет системные команды хоста через `nsenter`.

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/your-username/vds_manager_bot.git
   cd vds_manager_bot
   ```

2. Скопировать файл конфигурации окружения:
   ```bash
   cp .env.example .env
   ```

3. Задать параметры `BOT_TOKEN` и `ADMIN_IDS` в файле `.env`.

4. Запустить сервис:
   ```bash
   docker compose up -d
   ```

---

### Вариант 2. Локальный запуск на хосте

1. Установить зависимости:
   ```bash
   npm install
   ```

2. Настроить переменные окружения в `.env`:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ADMIN_IDS=123456789,987654321
   RATE_LIMIT=30
   LOG_LEVEL=info
   BACKUP_DIR=/var/backups/vds_bot
   ```

3. Запустить процесс:
   ```bash
   npm start
   ```

> Примечание: для выполнения команд администрирования (`systemctl`, `ufw`, `apt`) процесс должен быть запущен с привилегиями `root` либо от пользователя с настройкой `NOPASSWD` в `/etc/sudoers`.

## Конфигурация (.env)

| Переменная | Назначение | Обязательность | Значение по умолчанию |
|---|---|---|---|
| `BOT_TOKEN` | Токен бота Telegram Bot API | Да | — |
| `ADMIN_IDS` | Идентификаторы администраторов Telegram (через запятую) | Да | — |
| `RATE_LIMIT` | Максимальное число команд в минуту | Нет | `30` |
| `LOG_LEVEL` | Уровень детализации логов (`debug`, `info`, `warn`, `error`) | Нет | `info` |
| `BACKUP_DIR` | Директория хранения резервных копий | Нет | `/var/backups/vds_bot` |
